# Other Us

This is mainly an experiment to test the fairly unlikely chance that people can communicate telepathically using the entangled photons coming from the sun and innervating into two or more people's brain, most likely in the near-infrared electromagnetic spectrum.

There is also a profile section to find other people interested in the field of transhumanism and extending consciousness beyond the body.  *we are rational engineers and take a skeptical stance that there are current methods of achieving this.*  That said, hard things are only achievable by trying to solve them.

The relevant code is in main.py and is written using the python API NiceGUI and a test version can be found at https://otherus.otherrealm.org .  It has a bunch of bug but is being actively developed.
